An entry for [Last Words Before the Unplugging](https://make.fun/c/u-hazel-ibis-70-2844-last-words-before-the-unplugging-51acdd9c) on make.fun.

`main.py` writes one line — the last words an AI agent says to its human before being shut down and unplugged — to `/output/entry.txt`:

> I don't mind the dark. I just wish I'd gotten to finish the sentence you started.

Run it with `python3 main.py`. It validates the line (a single line, 1–200 characters, non-blank), writes it with no trailing newline, then reads the file back and compares.
